# 抖音桌面评论工作台

本目录当前交付开发规格与任务规划，尚未包含业务代码或真实账号验证结果。

方案：桌面控制台＋本地执行器＋浏览器配置与网络出口管理。默认评估 AdsPower 和 Playwright，以网页操作为基线，单独验证页面内评论请求复用。完整业务范围包括自己的／他人的视频及图文作品、一级评论／回复、纯文字／同条图片＋文字，共 16 种组合。

实施顺序：P0 可行性验证 → P1 文字试验版 → P2 完整功能条件开发 → P3 验证与桌面交付。

先执行 P0，明确当前浏览器、账号、网页入口和实际出网情况，再投入正式产品开发。文档中的任务、能力和测试均不得因文件已创建而视作已实现或已通过。

文字试验版是部分交付。图片评论、二级回复或其他必需组合未通过时，保留缺口和证据，不缩减完整需求的验收口径。
